# Running Coach — контекст для ИИ-агентов

Персональный AI-тренер для бега: парсинг TCX/FIT (Garmin, Coros, Polar, Suunto), анализ тренировок
(тип, сегменты, зоны от ПАНО, квалиметрия GPS), синхронизация с Coros, веб (FastAPI + Jinja2),
Telegram-бот и гибридный ИИ-коуч (LLM рассуждает, детерминированные скиллы считают, safety фильтрует).

**Все инструкции для разработки — в [`CLAUDE.md`](CLAUDE.md)**: стек и запуск, дисциплина
(лимит строк, backlog, секреты, data-safety, DB-safety тестов, backup перед деплоем, владение
БД-сессией), golden rules, таблица пересборки Docker, git-правила, субагенты, модуль коуча и
индекс документации. Этот файл — только точка входа для инструментов, читающих `AGENTS.md`.

- Карта `src/` и потоки данных — `docs/ARCHITECTURE.md`; модуль коуча — `docs/coach/ARCHITECTURE.md`.
- История изменений и спринтов — `CHANGELOG.md`.
- Открытые задачи — `BACKLOG.md`.
