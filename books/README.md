# books/ — исходники книг для дистилляции в базу знаний коуча

Положите сюда книги по любительскому бегу (**3–6 штук**), затем скажите агенту —
он прогонит `bin/distill_books.py` и превратит их в конспекты-гайды
(`src/coach/knowledge/guides/`), которые читает ИИ-тренер.

- **Форматы** (по качеству извлечения): `.epub` / `.fb2` → `.txt` / `.md` →
  `.pdf` с текстовым слоем. Сканированные PDF не годятся (нужен OCR).
- **Копирайт**: содержимое `books/` в git НЕ попадает (.gitignore); в репозиторий
  коммитятся только конспекты своими словами.
- Зависимости для извлечения: `pip install -e ".[distill]"` (локально, не в прод).
